# Public starter sources

The public template contains no applicant data or private employer-board list. Read `skills/job-application/references/public-sources.json` when the private catalog has no autonomous sources. The owner chat searches these sites in Chrome and observes source budgets and access challenges.

A private installation keeps its own `references/sources.json`. Skill updates must preserve that file. Read-only server feeds can be configured using `config/discovery.example.json`. No campaign runner or background browser is installed. Relevant roles join the passive queue only when the session explicitly requests it.
