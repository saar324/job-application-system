# Submission delegation

An owner request to apply authorizes the chat to review and submit routine job applications. Save the request reference with the final form review. Do not request a separate final approval for every application. The passive server records the exact reviewed fields and the one-use final-action checkpoint. It never clicks Submit.

Saved owner facts and scoped recruitment consent remain usable. They do not cover unrelated Terms, contracts, payment, identity changes or unknown answers. Follow the browser tool's action-specific confirmation rules. Stop on such a blocker and wait in the same form.

Existing versioned standing-policy records remain in profile history. Their caps remain useful. The retired worker's source-host permit system does not govern routine Chrome queue submission. See [the current workflow](agent-led-workflow.md).
