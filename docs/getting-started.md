# Getting started

Install Node 22.5 or later, run `npm ci`, then provision ignored profile and token files from the public examples. Set the paths in a private environment file. Configure approved résumé roots. Start the API with `npm start` and check `/health` reports `chrome_session`.

Install the job-application skill into the owner's chat runtime. Preserve private source settings, writing style and its profile-bound credential. Read [the workflow](agent-led-workflow.md).

Send job links in the same chat. The session queues them durably, applies in Chrome one at a time and records verified employer evidence. New links can be appended while it works or waits. A CAPTCHA or missing fact stops the current application and all discovery until the owner resolves it.
