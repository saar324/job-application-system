# Production rollout validation

The rollout verification covered service health, profile isolation, scoped submission authorization, hashed credential-map migration, source budgets and browser-path rollback. Agent credentials remain separate from owner credentials, and profile identity comes from authentication.

Private deployment configuration, policy scopes, applicant identities, source selections, configuration digests and per-applicant rollout evidence are retained outside this public repository. Use the generic deployment and standing-authorization documentation to configure a separate installation.

A service-health check or passing test suite does not establish a completed application campaign. Count only independently verified employer receipts; preserve holds, unknown outcomes and unresolved throughput criteria.
